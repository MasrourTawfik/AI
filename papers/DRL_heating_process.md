# A Deep Reinforcement Learning (DRL) Decision Model for Heating Process Parameters Identification in Automotive Glass Manufacturing

**Authors:** Choumicha El Mazgualdi, Tawfik Masrour, Ibtissam El Hassani, Abdelmoula Khdoudi  
**Venue:** Artificial Intelligence and Industrial Applications: Smart Operation Management  
**Pages:** 77–87  
**Publisher:** Springer  
**Year:** 2021  
**DOI:** https://doi.org/10.1007/978-3-030-51186-9_6

## Research summary

This work studies whether deep reinforcement learning can identify suitable heating-process parameters for tempered-glass manufacturing. The proposed decision system combines a Deep Q-Network (DQN) agent with a predictive neural model so that process settings can be selected from desired output conditions rather than being determined only by repeated manual trial and error.

The study is an industrial application of reinforcement learning to process parameter configuration and provides a basis for subsequent work on autonomous optimization and energy-aware smart manufacturing.

## Keywords

Deep reinforcement learning; DQN; industrial AI; smart manufacturing; process parameter identification; tempered glass; autonomous control.
