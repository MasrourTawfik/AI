# Towards an Improved CNN Architecture for Brain Tumor Classification

**Authors:** Hajji Tarik, Masrour Tawfik, Douzi Youssef, Serrhini Simohammed, Ouazzani Jamil Mohammed, Jaara El Miloud  
**Venue:** Innovation in Information Systems and Technologies to Support Learning Research  
**Pages:** 224–234  
**Publisher:** Springer  
**Year:** 2020  
**DOI:** https://doi.org/10.1007/978-3-030-36778-7_24

## Research summary

This work compares several established convolutional neural network architectures for brain-tumor classification from medical images and studies an alternative CNN architecture intended to achieve strong classification performance with practical learning time.
