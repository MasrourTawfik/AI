# Improved Hourly Prediction of BIPV Photovoltaic Power Building Using Artificial Learning Machine: A Case Study

**Authors:** Mouad Dourhmi, Kaoutar Benlamine, Ilyass Abouelaziz, Mourad Zghal, Tawfik Masrour, Youssef Jouane  
**Venue:** Emerging Trends in Intelligent Systems & Network Security

**Publisher:** Springer  
**Canonical DOI:** https://doi.org/10.1007/978-3-031-15191-0_26

## Research summary

This work studies short- and medium-term hourly photovoltaic power prediction for building-integrated photovoltaic (BIPV) systems. Multiple machine-learning regressors are compared using irradiance and weather variables relevant to PV production.
